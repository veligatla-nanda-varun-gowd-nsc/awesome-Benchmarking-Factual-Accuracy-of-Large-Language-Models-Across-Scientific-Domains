# Factual Accuracy Evaluation Tools & Frameworks

This tracking document catalogs open-source infrastructure and analytical libraries deployed to check language model assertions and automate fact-checking pipelines.

## 📌 Framework Registries

*   **Ragas (Retrieval-Augmented Generation Assessment)**
    *   **Purpose:** Programmatically evaluates context architecture recall, retrieval precision, and textual output faithfulness.
    *   **Official Link:** [Ragas Documentation Portal](https://ragas.io)
    *   **Source:** [explodinggradients/ragas on GitHub](https://github.com)

*   **TruLens (LLM Applications Auditor)**
    *   **Purpose:** Implements programmatic evaluations called the "RAG Triad" to track grounding issues, context relevance, and model hallucinations.
    *   **Official Link:** [TruLens Framework Main Page](https://trulens.org)
    *   **Source:** [truera/trulens on GitHub](https://github.com)

*   **DeepEval (The Open Source LLM Unit Testing Framework)**
    *   **Purpose:** Unit testing library for language architectures to lock in factual consistency thresholds and catch unexpected semantic regression patterns.
    *   **Source:** [confident-ai/deepeval on GitHub](https://github.com)

*   **Promptfoo (CLI Evaluation Engine)**
    *   **Purpose:** CLI tool designed to run assertion evaluation passes, checking outputs against user-configured strict constraints.
    *   **Official Link:** [Promptfoo Platform](https://promptfoo.dev)
    *   **Source:** [promptfoo/promptfoo on GitHub](https://github.com)

*   **Phoenix (AI Observability & Trace Evaluations)**
    *   **Purpose:** Open-source platform optimized to track data drift, log contextual traces, and visually record alignment scores.
    *   **Official Link:** [Arize Phoenix Platform](https://arize.com)
    *   **Source:** [arize-ai/phoenix on GitHub](https://github.com)
